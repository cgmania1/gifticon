## 디자인 (2026-09-30, 수강생 작업 + 다듬기)

수강생이 직접 만든 **Family Gift** 디자인(선물 상자 로고, Warm Ivory · Terracotta · Deep Plum · Sage · Butter 팔레트, 대시보드 히어로, 카드 UI, 메뉴 아이콘, 앱 아이콘·manifest)을 그대로 가져왔습니다. 여기에 첫 화면 빈 곳을 채우는 그림(선물 상자에서 펼쳐지는 교환권 · 가장 먼저 끝나는 날짜를 보여 주는 달력과 D-day 배지 · 가족 쿠폰 지갑 휴대폰 — 숫자는 실제 보관함 데이터)과 가벼운 움직임(움직임 줄이기 설정·탭 숨김·화면 밖에서는 멈춤)을 더하고, 글자 대비를 모두 4.5:1 이상으로, 좁은 화면 메뉴를 한 줄 다섯 칸으로 정리했습니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data09-21/**

처음 열면 **체험 모드**입니다. 예시 가족(엄마·아빠·첫째·둘째)과 기프티콘 8장(금액형 1장 포함)이 들어 있고, 이 브라우저에만 저장됩니다. 사진은 가상 상호·가짜 바코드로 그린 예시 그림입니다.

**가족과 함께 쓰려면** 본인 Supabase 프로젝트를 만들고 [supabase/README.md](supabase/README.md) 순서대로 `supabase/schema.sql` 을 실행한 뒤, 앱 「설정」에 Project URL 과 anon 키를 넣습니다. 그다음 가족 각자 이메일로 가입하고, 한 사람이 가족을 만들어 **초대 코드**를 알려 줍니다. 주소·키는 그 브라우저에만 저장되며 이 저장소에는 어떤 키도 없습니다.

내 PC에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(Supabase 라이브러리·글자 읽기 엔진은 `vendor/` 에 포함). **무료 글자 읽기는 파일로 연 화면(file://)에서는 브라우저가 막으므로** Pages 주소나 `http.server` 로 연 화면에서 씁니다.

| 메뉴 | 하는 일 |
|---|---|
| 보관함 | 가족 알림 띠(유효기간 임박, 가족 누구나 봄) + 「오늘의 알림 모두 가족에게 보내기」, 알림 시점 안 카드마다 「가족에게 보내기」(휴대폰 공유 창 → 카카오톡, 또는 문자 앱 — 무료, 보내기는 직접 누름), 요약 4칸 = 거르기 단추(사용 가능 · 7일 이내 만료 · 사용함 · 만료), 유효기간 빠른 순 카드(큰 D-day 배지 + 글자 풀이, 사진 썸네일 → 크게), 카드마다 「사용함」 체크·예약자·고치기·삭제, 금액형은 잔액 표시 + 「금액 사용」(잔액 0 이면 사용함) |
| 등록 | 캡처 사진 올리기(미리보기) + 상품명·발행처·유효기간·메모·예약자 + 금액형(액면가·잔액). 접힌 「사진에서 채우기 (선택)」 — ① 무료 글자 읽기(이 기기 안 OCR, 키 없음, Pages 주소에서) ② Copilot·Gemini·ChatGPT 무료판 반자동 ③ 내 OpenAI 키(선택) |
| 기록 | 등록 · 수정 · 사용 · 금액사용(쓴 금액·잔액) · 사용취소 · 예약 · 삭제 — 한 사람·시각, 최근 순(고치거나 지울 수 없음) |
| 가족 | 초대 코드, 구성원, 문자 받을 번호(선택, 이 기기에만), 내 표시 이름 (체험 모드: 「지금 쓰는 사람」 바꾸기) |
| 설정 | 알림 시점(기본 D-7·D-2·D-1), DB 연결, 체험 데이터 다시 채우기·지우기 |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음) — OCR 칸 나누기 규칙은 `test/ocr-samples/` 가짜 기프티콘 그림 9장(8·9 는 수강생 실제 캡처의 배치를 흉내 낸 그림)과 실제 캡처를 읽은 글자로 검사. 실제 캡처 사진은 저장소에 넣지 않음
- DB 스크립트 검증: `./scripts/sqltest/run.sh` (로컬 PostgreSQL 필요, 옛 판 DB 올림 검사 포함)

## 1단계 구현 범위

| 요청 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 가족이 함께 등록·관리 | 완료 | 이메일 로그인, 가족 만들기·초대 코드, 같은 가족만 보기(RLS) |
| 사진으로 등록 | 완료 | 사진 올리기·비공개 저장·크게 보기. 사진에서 상품명·발행처·유효기간 채우기는 **선택 도우미**(무료 OCR / 무료 AI 채팅 반자동 / 내 OpenAI 키). 무료 OCR 은 수강생 실제 캡처 2장으로 규칙을 보강(브랜드 목록·로고 줄 거르기·줄 끝 「5만원」 금액·색 배경 지운 두 번째 읽기) — 두 장 모두 네 칸이 맞음. 바코드 번호는 읽지 않음 |
| 사용 여부 표시·삭제 | 완료 | 「사용함」 체크(누가·언제 기록, 되돌리기), 삭제 |
| 발행처 자동 사용 확인 | 하지 않음 | 공개 조회 경로가 없고 긁어오기는 약관·보안 위험 — 가족이 직접 체크(강사 결정) |
| 일정별 알림 | 완료 | 알림 시점 설정(기본 D-7·D-2·D-1) + 앱 안 가족 알림 띠 + **가족에게 보내기**(휴대폰 카카오톡·문자로 무료, 직접 누름 — 수강생 휴대폰에서 잘 됨 확인). 정해진 시각 **유료 자동 발송은 하지 않음**(수강생: 필요 없음) |
| 사용 예약 | 완료 | 가족 구성원 중 예약자 선택(DB 가 같은 가족만 허용) — 「누가 쓸지 표시」 |
| 금액형 잔액 | 완료 | 액면가·잔액, 나눠 쓰기(DB RPC), 잔액 0 이면 사용함, 기록 「금액사용」 |
| 등록·사용 기록 | 완료 | DB 트리거가 덧붙이는 기록 표(고치기·지우기 불가) |

개발 기록: [docs/개발일지.md](docs/개발일지.md)
